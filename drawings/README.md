# The Curta Type I factory drawings

All 257 sheets of Contina AG's drawing set for the Curta Type I (1948–1952).

- **[Curta-Type-I-Contina-drawings.pdf](Curta-Type-I-Contina-drawings.pdf)**: every sheet in one bookmarked PDF (38 MB). Page 1 is a title page, so sheet *n* is PDF page *n + 1*.
- **sheets/**: each sheet as its own image, listed below.

**Rights.** The drawings are the work of Contina AG, Mauren, and are in the public domain. The scans, English translations and this index are by **Chris Hurt, [curta-drawings](https://github.com/cshurt64/curta-drawings)**, licensed [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/): reuse them freely, crediting "Chris Hurt, curta-drawings". His repository also has a dimensional audit of each part and higher-resolution scans of some sheets.
